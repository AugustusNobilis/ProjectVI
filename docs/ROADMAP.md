# Roadmap

1. Expand hand-authored PE and API-set fixtures, including malformed inputs and importer-specific aliases.
2. Add focused ABI experiments with expected outputs and explicit unsupported cases.
3. Extend memory experiments to document host behavior before implementing additional mappings.
4. Develop independently reviewable loader and graphics components, with synthetic tests before game-specific claims.
5. Report a game milestone only when the published implementation and reproducible evidence support it.

There is no promised release date or playable-build download. Each step should produce testable code and document its remaining limits.
