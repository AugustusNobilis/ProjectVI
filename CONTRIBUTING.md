# Contributing

Describe the concrete behavior being changed and how to reproduce it. Keep changes focused and run the checks in the README.

- Use English for documentation, comments, issues and user-facing messages.
- Use hand-authored or generated synthetic fixtures.
- Do not upload game files, extracted assets, keys, proprietary SDK content, memory dumps or raw package reports.
- Preserve the license and attribution of any third-party code you propose to introduce.
- State which checks were run, the operating system and relevant hardware, and whether AI assistance was used.
- Separate observed behavior from hypotheses and unsupported cases.

For a bug report, provide the failing synthetic test or a minimal description that does not require publishing proprietary content. Do not attach a game executable or package.
